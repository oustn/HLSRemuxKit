# HLSRemuxKit 0.1 Plan Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close all gaps between the 0.1 implementation and its design with transactional output installation, deterministic cancellation, complete error semantics, and real iOS simulator media tests.

**Architecture:** Put platform-independent file and operation state logic in `HLSRemuxCore`, where macOS unit tests can exercise it without FFmpegKit. Keep the public async API and the thin FFmpegKit adapter in `HLSRemuxKit`, and use Swift Package XCTest resources for real iOS-only integration coverage.

**Tech Stack:** Swift 5.9 package, Foundation, Swift Testing, XCTest, AVFoundation, FFmpegKitNext wrapper 8.1.1, FFmpeg 8.1.2, Xcode 16.4, `xcodebuild`, `simctl`, `ffmpeg`, and `ffprobe`.
