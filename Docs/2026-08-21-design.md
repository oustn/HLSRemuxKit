# HLSRemuxKit Design

## Goal

Provide a reusable iOS 16 Swift Package for lossless HLS media remuxing. The first release supports MPEG-TS input to MP4 output and local fragmented-MP4 HLS playlists to MP4 output. It never decodes or re-encodes media.

## Architecture

- `HLSRemuxCore` owns platform-independent command construction and remains testable on macOS.
- `HLSRemuxKit` owns the public async API and the FFmpegKitNext bridge.
- `Vendor/FFmpegKitNext` pins the FFmpegKitNext wrapper 8.1.1 with FFmpeg 8.1.2 libraries for arm64 iOS. The package also declares every dependent FFmpeg framework so consumers get a complete link set.
- A future self-built FFmpeg package can replace the vendor archives without changing the Swift API.

## API

`HLSRemuxer.remuxTS(input:output:progress:)` and `HLSRemuxer.remuxFMP4Playlist(input:output:progress:)` take local file URLs, create parent directories, and return an `HLSRemuxResult` with the output URL, byte count, and duration. `cancel()` cancels the active FFmpeg session. One remuxer accepts one active operation and reports `operationInProgress` for overlap; callers can create separate instances for concurrency. Progress is optional and throttling is left to the caller.

## Data flow and safety

The command uses `-map 0 -c copy`, with `+faststart` as a container-only relocation. Paths are passed as individual FFmpeg arguments, so spaces do not require shell quoting. FFmpeg writes to a unique temporary MP4 beside the destination. A successful run atomically installs that file; a failed or cancelled run removes only the temporary file and preserves any existing destination.

## Testing

The host test layer verifies command construction, the no-reencode contract, output transactions, operation state, cancellation races, and error mapping. Automated arm64 iOS simulator tests run real H.264/AAC TS and fragmented-MP4 fixtures through FFmpegKitNext, then verify the resulting MP4 exposes video and audio tracks. The validation script also type-checks the arm64 device slice; physical-device execution is an optional manual check.
